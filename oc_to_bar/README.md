# 広東バー（金沢・彦三町）公式LINE 受付ページ — oc_to_bar

金沢市彦三町のバー「広東バー」専用の、**LINEのトーク画面を再現した**受付ページです。
チャット形式でご予約・お問い合わせができ、下部にはLINE公式アカウント風のリッチメニューが付いています。

- 公開URL（GitHub Pages）: `https://isobetadamichi.github.io/bodymente/oc_to_bar/`
- サーバー不要。送信内容は **公式LINEのトークに本文入りでセットされて送信** されます（`line.me/R/oaMessage` を使用）。

## 画面の構成（LINE風フォーマット）

| 部位 | 内容 |
| --- | --- |
| ヘッダー | 店名「広東バー｜ご予約・お問い合わせ」＋「自動で返信しています」 |
| トーク画面 | ボットの吹き出しが自動応答。予約は質問に1つずつ答えるチャット形式 |
| クイックリプライ | 「🍸 予約する」「🕐 営業時間」などの選択チップ |
| 入力バー | LINE風のメッセージ入力欄（自由入力→公式LINEへ送信） |
| リッチメニュー | 営業時間／アクセス／メニュー／友だち追加＋大きな「ご予約する」タイル。「メニュー ▼」で開閉 |

## セットアップ手順（要・人の作業）

公式LINEアカウントの作成はLINEへのログインが必要なため、以下を実施してください。

1. [LINE公式アカウントの開設ページ](https://www.lycbiz.com/jp/service/line-official-account/) から広東バー専用のアカウントを新規作成する（無料プランでOK）。
2. [LINE Official Account Manager](https://manager.line.biz/) で以下の2つを控える。
   - **ベーシックID**（`@` で始まるID）… 設定 → アカウント設定
   - **友だち追加URL**（`https://lin.ee/…`）… 友だちを増やす → 友だち追加ガイド
3. `oc_to_bar/index.html` 冒頭の `CONFIG` と `STORE` を書き換える。

```js
const CONFIG = {
  LINE_OA_ID: "@012abcde",                 // ← ベーシックID
  ADD_FRIEND_URL: "https://lin.ee/xxxxxxx" // ← 友だち追加URL
};
const STORE = {
  name: "広東バー",
  area: "石川県金沢市彦三町",
  address: "石川県金沢市彦三町◯-◯-◯ ◯◯ビル1F", // ← 正式住所に更新
  hours: "20:00〜24:00（不定休）",              // ← 実際の営業時間に更新
  ...
};
```

4. コミットしてpushすると、GitHub Pagesに反映されます。

## 動作仕様

- **予約フロー**: 名前 → 希望日（今日/明日/あさってのチップ or 自由入力）→ 時間 → 人数 → 要望 → 確認カード → 「公式LINEに送る」でLINEが本文入りで開く。
- **質問・相談**: 自由入力がそのまま公式LINEのトークにセットされる。
- **未設定時**: `CONFIG` が空の間はトーク内に管理者向け警告が出て、送信は「内容コピー」にフォールバック。
- 店舗情報（営業時間・住所・メニュー）は `STORE` を書き換えるだけでボットの返答に反映。

## おすすめの公式LINE側設定

- **あいさつメッセージ**にこのページのURLを入れる（友だち追加直後にチャットフォームへ誘導）。
- **リッチメニュー**をこのページと同じ構成（営業時間／アクセス／ご予約）で作ると体験が揃います。
